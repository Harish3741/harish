# Harish — a museum of things I have built

A portfolio you walk around in. It's a top-down pixel game: you play a small
hovering droid arriving at a museum, and the work is hung in four wings off a
central atrium — Automations, Initiatives, Projects, and an About Me room with
a cinema in it.

Walk up to something and press <kbd>E</kbd> to look at it.

## Why

> It felt boring to list out all the things I've done when trying to introduce
> myself. I wanted a fun way for someone to know what I've done so I decided to
> build an interactive game with a collection of everything I've done. Player is
> able to move around into different rooms and explore all the work I've done
> with photos and descriptions of each project.

Built with no framework, no dependencies and no build step — one `<canvas>` and
plain JavaScript. There's a plain list behind a button for anyone who would
rather just read it.
